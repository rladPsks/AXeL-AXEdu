# L1·L2·L3 화면 연결 및 시연 보완

2026-10-31. 이전 `미션_L1_L2_L3_구현점검_20261031.md`를 대체하지 않는 후속 구현 기록.

| 레벨 | 화면에서 확인할 기능 | 이번 연결 |
|---|---|---|
| L1 | 원문·분류·긴급도·담당 추천 | 기존 접수 상세 유지. 관리자가 수정 가능한 교사 요약·필요 행동 유지 |
| L1 | 근거 답변 | 답변 편집→새 버전 저장→관리자 승인→실제 전달 사실 기록. 답변 전달 기록 없이 종결 차단 |
| L1 | 전체 처리 이력 | 감사·업무·지원·AI 실행·활동·자료 버전·비교 자료·문서 수정/승인/내보내기를 한 탭에 통합 |
| L2 | 반복·누적 맥락 | 학교별 동일인 식별키와 동일 사안별 집계. 학교 미응답 가능성·새 정보·별도 사안을 구분 |
| L2 | 지원·이관 판단 | 기존 AI 검토 및 관리자 판단 화면을 레벨 안내에서 직접 연결. 횟수만으로 이관 확정하지 않음 |
| L2 | 감정 완화 | 저장 답변에 실제 AI 표현 조절 작업 요청, 원문/제안 대조·수정 이유·의미 확인 표시. 사람 적용 후 새 버전 저장·재승인 |
| L3 | 이관 서류 | 같은 사건·업무·관리자 판단·근거·첨부 목록으로 초안 생성. 편집/미리보기/승인/Markdown 파일 내보내기. 오래된 판단/문서 차단 |
| L3 | 노출도·처리시간 | 기존 관리자 대시보드를 전면 연결. 실제 기록 시간과 미기록을 구분 |
| L3 | 다국어 | 원문/한국어 번역 대조·수정·버전·검토 확정. 확정 번역은 이후 AI 지원 검토 입력에 사용 |
| L3 | 동의 녹취 | 기존 동의→음성→전사 정정→구간 인용 요약 흐름을 레벨 안내에서 직접 연결 |

## 반복 시연 데이터
`demo-pattern-01`~`07`: 가상민원인 나○○의 7건. 동일 사안 6건과 별도 사안 1건. 4차 새 자료, 5차 가상 답변 전달, 6차 답변 이후 같은 요청. 가상 전달 기록은 실제 외부 발송 증명이 아니다. 시연 DB에서만 중복 없이 추가한다. 기존 20건은 보존한다.

## 확인 범위와 남은 한계
- UI와 저장·권한·버전 충돌·오래된 서류 차단·번역 분석 연결은 자동 테스트 및 배포 확인 대상으로 구분한다.
- 학교 시스템 자동 수신, 외부 답변 발송, 교육지원청 공식 제출 API는 미연동이다. 수동 원문 접수·실제 전달 사실 기록·파일 내보내기 범위를 화면에 명시한다.
- 학교별 실제 규정/일정 자료의 충분성, AI 분류·표현 조절·번역의 의미 보존 정확도, 녹취 품질은 학교 자료와 실제 샘플에 대한 별도 평가가 필요하다. 모의 테스트 통과를 모델 품질 검증으로 표현하지 않는다.
- 대시보드의 단계별 대기시간 및 민원/상담/복합 상세 분리 등 PRD 확장 수용 기준 전체를 완료했다고 주장하지 않는다.
- 이력 탭은 저장된 처리 기록을 통합하며 과거에 기록되지 않은 행동을 복원하지 않는다. 일반 조회/열람 자체의 전수 감사는 범위에 포함되지 않는다.
- 동일 이름만으로 동일인 확정하지 않는다. 새 패턴 탭은 확인된 식별키를 사용한다. 기존 접수의 이름 기반 이력은 후보이며 사람이 확인해야 한다.
