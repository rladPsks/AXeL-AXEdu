# 「함께」 2차 피드백·디자인 반영

기준: 다운로드의 `함께_사용자테스트_피드백 (1).md`, `함께_디자인전달.md`.
피드백 파일은 1차와 같은 내용이고, 새 변경 기준은 디자인 전달 v2입니다.

- [x] 햇살 노랑·밝은 크림 사이드바·따뜻한 먹색으로 교체. 지정된 라이트 컬러 토큰 적용
- [x] 본문 18px, 메뉴 19px, 제목 36px, 랜딩 44px(모바일 34px), 버튼 20px, 숫자 44px
- [x] 로그인 첫 화면: 로고 → 핵심 문구 → 설명 → 교장·교감·교사 역할 카드 3개
- [x] 가운데 교사를 교직원들이 감싸는 우산 SVG 일러스트. 학부모 미포함
- [x] 기존 노랑·초록 로고와 파비콘 유지
- [x] 로고 클릭·상단 ‘처음 화면’으로 역할 선택 화면 복귀
- [x] 사이드바 하단 슬로건, 상단 사용자명·학교명
- [x] 목록 순서: 제목 → 3단계 숫자 타일 → 정보·주의 안내 → 민원 카드
- [x] 단계 표기: ‘단순’, ‘살펴보기’, ‘함께 대응’. 분류 없는 기존 민원은 ‘분류 전’으로 표시
- [x] 실제 저장된 분류를 기반으로 단계 표시. 타일은 불러온 목록 기준임을 명시하고 기존 학교·교사별 접근 범위 유지
- [x] 민원 카드의 단계·제목·접수 경로·일시·담당 표시
- [x] 관련자 아래 접수 경로(선택)·발생 일시 2열 배치, 경위·원문 도움말, 노랑 버튼·전송 안내
- [x] 발생 일시를 접수 시각과 별도로 저장·표시. 기존 DB는 새 SQLite 마이그레이션으로 보존
- [x] 조직도: 팀장(교장) → 총괄(교감) → 행정실장 / 교무부장 / 생활인성부장. 미등록 직위에는 빈 상태 표시
- [x] PC·390px 모바일·다크 모드 및 역할 전환·설정 저장 브라우저 검증
