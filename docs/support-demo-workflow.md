# 관리자·지원 담당 포함 시연 워크플로우

공개 시연: https://axel-axedu.vercel.app · 권장 시간 5분.
모든 인물·민원·활동·답변은 가상이다. 기록 시간은 실제 업무 평가에 사용하지 않는다.

## 1. 학교 전체 대응 현황 보기 (1분)

김갑수 교장으로 로그인 → 교사별 민원 노출도·처리시간 → 새로고침.
조회 기간은 오늘을 포함한 최근 30일로 설정한다.
‘관리자·지원 담당도 포함’을 켜고 다음 역할의 이름을 차례로 선택한다.

| 담당자 | 연결된 시연 민원 | 기록된 시간 | 현재 대기 업무 |
|---|---|---|---|
| 김갑수 교장 | 지도 기준 설명 요청 | 지원 검토 20분 | 학교 공식 답변 최종 검토 |
| 이정희 교감 | 학교 답변을 기다리는 재문의 / 새로운 자료를 첨부한 문의 | 상담 25분 + 시간 미기록 협의 1건 | 동석 상담 일정·창구 확인 |
| 최유진 교무부장 | 첫 생활지도 문의 | 기준·업무분장 확인 15분 | 지도 기준 확인 |
| 박민수 행정실장 | 별도 사안: 홈페이지 사진 | 게시 동의 확인 10분 | 비공개 처리 절차 확인 |
| 한서윤 생활부장 | 새로운 자료를 첨부한 문의 | 사실확인 상담 30분 | 새 자료·기록 대조 |
| 오○○ 업무지원 | 답변 이후 동일한 요청 | 전달 확인 콜백 8분 | 이전 답변 전달 여부 확인 |

표의 값은 최초 샘플 기준이다. 시연 중 기록하거나 완료한 업무는 집계에 반영된다.
교감의 시간 미기록 1건은 0분이 아니며 기록률을 설명하는 예시다.

발표 멘트: “교사의 부담만 보여주는 것이 아니라, 학교의 어느 담당자가 어떤 지원을 수행하는지 같은 민원 안에서 확인합니다.”

## 2. 생활부장에게 필요한 사실만 확인 (1분)

한서윤 생활부장 상세 → ‘새로운 자료를 첨부한 문의’ → 대기 업무 확인.
생활부장 계정으로 전환해 같은 민원의 본인 업무를 확인하고, 확인 → 회신·완료한다.

예시 회신:

> [가상 시연] 제출된 활동 기록에 기존 문의에 없던 쉬는 시간 주장이 포함되어 있습니다. 수업 기록과 일치하는 부분은 확인했으며, 쉬는 시간 상황은 추가 확인이 필요합니다. 보호자에게 직접 연락하지 않았습니다.

학교 사건 총괄과 사실확인 업무 수행자는 별개임을 설명한다.

## 3. 교감이 학교 지원 조율 (1분)

교감 계정 → ‘학교 답변을 기다리는 재문의’의 상담 업무 확인.
학교 지원 탭에서 교사 동석·공동 대응이 필요한 이유를 기록하고 담당자를 지정한다.
업무시간 기록에는 실제 시연에서 입력하는 시간을 별도 가상 활동으로 남긴다.

예시 회신:

> [가상 시연] 담임과 생활부장이 확인한 사실을 취합하고 학교 창구에서 답변하기로 협의했습니다. 상담이 필요하면 교감이 동석하며 일정은 보호자와 별도로 조율합니다.

## 4. 답변 재검토와 사람 승인 (1분)

교장 계정으로 전환 → 새 자료 민원의 AI 지원 검토 실행.
확인된 사실·보호자 주장·미확인 내용과 답변 초안을 확인한다.
새 자료 확인 전후로 무엇이 바뀌었는지 설명하고, 학교 권한자의 최종 검토 단계까지 보여준다.
AI가 사용 불가하거나 지연되면 저장된 접수 분석과 방금 입력한 업무 회신을 보여준다.
저장된 가상 분류는 실제 모델 실행 결과라고 설명하지 않는다.

## 5. 집계로 돌아가 지원 결과 확인 (1분)

현황 화면 → 새로고침 → ‘관리자·지원 담당도 포함’ 선택.
생활부장의 대기 업무 감소와 새 활동 기록을 확인한다.
업무 완료와 시간 기록은 별도이므로 완료만 해서는 기록 시간이 자동 증가하지 않는다.
행정실장 상세에서는 사진 공개 동의처럼 생활지도와 다른 사안도 해당 담당에게 분리되는 모습을 보여준다.

## 시연 준비·재실행

- 공개 서버 샘플 추가: `.\.venv\Scripts\python.exe tools/populate_support_demo.py`
- 로컬 시연 서버는 `SCHOOL_AGENT_AUTO_SEED=1`, `SCHOOL_AGENT_DEMO=1`로 실행하면 시작 시 샘플을 추가한다.
- 추가 스크립트와 자동 시드는 기존 샘플을 중복 생성하거나 완료한 업무를 다시 열지 않는다.
- 업무 완료 시연을 반복할 때는 동일 민원에 새로운 가상 업무를 요청한다. 기존 회신·감사 기록은 보존한다.
- 공개 서버의 데이터 추가는 즉시 반영된다. 기록 없는 관리자 표시와 화면 안내 문구 변경은 수정한 코드 배포 후 적용된다.
